# Code of Conduct

## Our Standard

This project is open to people who want to improve local, source-linked tools for
understanding Danish tax information. Participation should be practical,
respectful, and focused on the work.

Expected behavior:

- Be respectful of different experience levels and backgrounds.
- Keep discussion technical, factual, and relevant to the project.
- Give and receive feedback in good faith.
- Avoid sharing personal tax data, identity documents, credentials, or other
  sensitive information in issues, pull requests, discussions, or logs.
- Respect that this project is not a place to request personal tax advice.

Unacceptable behavior:

- Harassment, threats, discriminatory language, or personal attacks.
- Publishing private information without explicit permission.
- Spam, repeated off-topic posts, or attempts to use the project for fraud.
- Encouraging users to submit unreviewed or misleading information to public
  authorities.

## Enforcement

Maintainers may edit, hide, or remove comments, issues, pull requests, or other
contributions that violate this code of conduct. Maintainers may also block
participants when needed to protect the project.

If you need to report a concern, contact the maintainers through GitHub issue
moderation tools or a private channel made available on the repository.

Maintainers will handle reports with reasonable confidentiality, but this is a
public open-source project and cannot provide legal, financial, or tax advice.
