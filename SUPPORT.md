# Support

## Where To Get Help

Use GitHub Issues for:

- Reproducible bugs.
- CLI installation problems.
- Parsing or scraping failures.
- Documentation fixes.
- Feature requests.

Use a minimal reproduction and dummy data. Do not include CPR numbers, MitID
details, tax documents, bank data, filled PDFs, or private SQLite databases.

## What This Project Does Not Provide

Maintainers and contributors cannot provide:

- Personal tax advice.
- Legal, accounting, or financial advice.
- Help filing through TastSelv.
- Review of your private tax return or supporting documents.
- Emergency or guaranteed-response support.

For personal tax questions, use official Skattestyrelsen channels or a qualified
professional adviser.

## Useful Diagnostics

When reporting a technical issue, include:

```bash
taxhelper --version
python --version
taxhelper stats --json
```

Also include your operating system and how you installed the CLI.
