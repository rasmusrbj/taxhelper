taxhelper

A free, open-source CLI and MCP server for looking up Danish årsopgørelse rubrikker, official Skat guidance, tags, source links, and PDF review workflows in a local SQLite database.

Install

One command, local data

The installer uses pipx, refreshes the Agent Skill for Codex and Claude Code, and tries to install Poppler for PDF extraction.

macOS/Linux

curl -fsSL https://raw.githubusercontent.com/rasmusrbj/taxhelper/main/install.sh | sh
taxhelper init
taxhelper lookup "field 417"

Windows PowerShell

irm https://raw.githubusercontent.com/rasmusrbj/taxhelper/main/install.ps1 | iex
taxhelper init
taxhelper lookup "field 417"

What it does

Search rubrikker, tags, official sources, and review templates

SQLite-backed lookup

Bootstrap a local tax_rules.sqlite database with rubrikker, structured seed rules, official source pages, FTS search, and tags.

Rubrik and felt search

Resolve natural language, rubrik numbers, and field numbers into source-linked context for Danish annual tax assessment review.

PDF review workflow

Generate a worksheet or fill a local copy of the official 04.003 Oplysningsskemaet PDF from explicit JSON values.

Agent-ready JSON

Use stable --json output for retrieval workflows, context gathering, templates, stats, and source-linked explanations.

Agents and MCP

Built for Codex, Claude Code, and MCP clients

taxhelper includes a stdio MCP server and an Agent Skill that tells coding agents how to use read-only lookup tools before answering tax return questions. 

taxhelper-mcp
taxhelper mcp
taxhelper install-skills --force
taxhelper context "can I deduct transport to work?" --json
